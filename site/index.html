What it does

In time, to the second

Time-synced lyrics from lrclib.net, interpolated between Spotify’s own position updates. One timer is set for the next line; nothing ticks in between.

Translated on your Mac

Pick the language you read and any of twenty source languages. Apple’s on-device models do the work; translated lines are marked with ⇄.

Weightless

460 KB on disk, about 40 MB in memory, and zero CPU while a song is paused. No polling, no background checks, no dependencies.

Goes where you put it

Turn on Move Mode, drag the pill anywhere on any screen, and it stays there. Font size and opacity are yours to set.

Honest status

The menu says exactly what’s happening: showing lyrics, no synced lyrics for this track, lyrics server unreachable, or a language pack to download.

Private by design

Only the song’s artist, title, album and length leave your Mac, to find the lyrics. No account, no analytics, no telemetry.

Settings

Everything lives in one small window: the overlay mode, launch at login, the pill’s look, and which languages to translate from.

Install in a minute

  1. Download and drag

    Open the DMG and drag LyricPill to Applications. Latest release.

  2. Open it once from Privacy & Security

    The build is signed but not notarized, so the first launch is blocked. System Settings → Privacy & Security → Open Anyway. macOS asks only once.

  3. Play a song

    macOS asks whether LyricPill may control Spotify — it only reads the current track and position. Allow it, and the line appears.

Prefer to build it yourself? git clone the repository and run ./install.sh with Xcode Command Line Tools.

Privacy

To find lyrics, the app sends the playing track’s artist, title, album and duration to lrclib.net over HTTPS. Nothing else, ever. Translation runs on-device. Checking for updates happens only when you click the button.
